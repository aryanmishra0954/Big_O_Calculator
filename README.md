# 🚀 Big O Complexity Analyzer

An AI-powered, full-stack web application that automatically analyzes C++, Python, and Java code to determine its Time and Space complexity (Big O notation) using the Google Gemini API.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Backend:** Node.js, Express.js
* **AI Engine:** Google Gemini 2.5 Flash API
* **Security:** `dotenv` for API key management

## 💻 How to Run Locally
1. Clone the repository to your machine.
2. Run `npm install` in the terminal to download dependencies.
3. Create a `.env` file in the root folder and add your key: `GEMINI_API_KEY="your_key_here"`
4. Start the server: `node backend/server.js`
5. Open `frontend/index.html` in your browser.
